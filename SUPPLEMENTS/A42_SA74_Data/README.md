# A42: run data

Everything the runs behind Sections 3 to 5.1 and 8.7 produced, for checking without rerunning. The scripts that make them are in A42_SA74 (see A42_SA74_README.md there).

- sa74_runs/: run outputs and logs: noise bands, update orders, causal-invariance checks, percolation, de Sitter tables, and sa74_numbers.json, every number the paper quotes from these runs.
- growth_engine/: the compiled sequential-growth engine's source and trajectories.
- regge/: the Regge gravity engine and driver, run plans, summaries (results.json, results_followup.json) and raw_runs/, the per-sweep histories and final configurations (about 26 MB).
- forms/, lattice/, transfer/: the form-fermion, supplied-lattice and step-rule transfer results.

The independent 24-chain Regge audit of Section 8.9 is A42_Regge_Audit_T19; its raw histories are regenerated by its scripts.
