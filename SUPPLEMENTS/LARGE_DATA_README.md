# Large data kept on GitHub only

Two supplement folders are too large for the portfolio zips and live only in the papers repository (MatheismOrg/papers, SUPPLEMENTS/):

- A19_Original_Analysis: the original dark-matter analysis code, inputs and saved results (about 72 MB), for the numbers the A19 number map marks "Rerun" or "Saved".
- A42_SA74_Data: the A42 run data, including the raw Regge histories (about 30 MB).

A19_Reproduce and A42_SA74 in this folder hold the code and smaller data that rebuild the papers' numbers.
