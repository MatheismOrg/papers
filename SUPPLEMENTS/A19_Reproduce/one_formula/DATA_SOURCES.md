# External data in this folder: sources and terms

Every external file here is a small table of published values, kept so that the scripts rerun without a network. Please cite the original sources when you use the values, not this repository. The terms are given as we understand them. If you hold rights in a file and want it removed or credited differently, open an issue in this repository.

The data used by protocols 1 to 9 (SPARC, the Local Volume Database, the nearby-galaxy catalog of McConnachie, KiDS-1000, CLASH, MaNGA, X-COP, and the tables of Mandelbaum et al., Umetsu et al. and Hudson et al.) are one level up; `A19_Reproduce/README.md` lists their sources.
