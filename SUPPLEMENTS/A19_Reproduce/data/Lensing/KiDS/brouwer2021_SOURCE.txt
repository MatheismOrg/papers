The compact files were built in the browser from the archive members: each covariance element divided by its own
bias column (as the README requires), written to 6 significant digits; blocks in order, upper triangle within a
diagonal block; the hash of each compact string was computed in the browser and matches the file here. Every
element was present and the matrices are symmetric (checked in the browser). The radius lists in the compact
files are the g_bar bin centers, identical to the profile files' first column.

Conventions (README and B21): ESD_t and its error are divided by the bias column; g_obs = 4 G ESD; the 15 g_bar
bins are logarithmic between 1e-15 and 5e-12 m/s^2 (the files list each bin's arithmetic center); units h70.
Bins run from low to high observable value.
